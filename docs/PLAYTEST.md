## 环境准备

- [ ] 使用干净启动状态打开项目或构建包。

  - 证据：Console 截图或错误摘要。
- [ ] 将窗口或设备调整为 390x844。
  - 预期：大厅背景铺满，主按钮可点击，文字不重叠。

- [ ] 确认本次是否启用清空本地存档。

  - 证据：初始战绩记录。

## 一整局主流程

### 1. 大厅入口

- [ ] 查看大厅基础信息。
  - 操作：进入大厅，观察开始新局、新对局、设置、战绩、难度区域。
  - 预期：核心入口可见；难度状态可辨认；战绩区域不遮挡主按钮。
  - 证据：大厅截图。
- [ ] 打开或切换设置项。
  - 操作：切换音效、震动、动效等开关。
  - 预期：开关状态立即反馈；不影响开始新局入口。
  - 证据：设置状态截图或记录。
- [ ] 切换难度。
  - 操作：在简单、普通、困难之间切换一次，最后停在本轮要测试的难度。
  - 预期：当前难度展示正确；重启前先记录最终选择。
  - 证据：难度状态记录。
- [ ] 进入新局。
  - 操作：点击开始新局或新对局。
  - 预期：进入牌桌；三名玩家座位、倍数、阶段提示、玩家手牌区域可见。
  - 证据：游戏首屏截图。

### 2. 叫抢阶段

- [ ] 检查叫抢提示。
  - 操作：等待进入叫地主 / 抢地主阶段。
  - 预期：当前行动玩家提示明确；叫地主、不叫、抢地主、不抢等按钮只在对应阶段可操作。
  - 证据：叫抢阶段截图。
- [ ] 检查叫抢建议。
  - 操作：观察建议文案或建议区域；若当前版本未接线，记录为待后续 UI 任务验证。
  - 预期：已接线版本应能给出低干扰建议；未接线版本不得出现阻塞性空白或错误。
  - 证据：建议区域截图或缺口记录。
- [ ] 完成叫抢。
  - 操作：选择一次叫地主或不叫；如轮到 AI，等待 AI 行动。
  - 预期：地主最终确定；底牌归属正确；倍数展示随叫抢变化。
  - 证据：地主确定后的牌桌截图。

### 3. 出牌回合

- [ ] 检查手牌和操作按钮。
  - 操作：选择一组可出的牌，观察出牌、不要、提示按钮状态。
  - 预期：手牌不遮挡主要按钮；按钮状态与当前是否有牌权一致。
  - 证据：选牌截图。
- [ ] 使用提示。
  - 操作：点击提示。
  - 预期：有可出牌时选中推荐牌；无可出牌时提示过牌或按钮状态正确。
  - 证据：提示后的手牌 / 按钮截图。
- [ ] 执行出牌。
  - 操作：点击出牌。
  - 预期：牌从玩家手牌移出；当前出牌区清晰展示；AI 后续行动不卡死。
  - 证据：出牌区截图。
- [ ] 执行不要。
  - 操作：在允许过牌时点击不要。
  - 预期：回合进入下一家；连续过牌后牌权回到上一手出牌玩家。
  - 证据：过牌前后阶段提示截图。

### 4. 炸弹 / 火箭与倍数

- [ ] 触发或记录炸弹 / 火箭场景。
  - 操作：若手牌或 AI 行动自然出现炸弹 / 火箭，观察动效和倍数；若本轮未出现，记录为“本轮未覆盖”，后续用固定种子或调试局补测。
  - 预期：出牌区局部动效清晰；倍数翻倍；不出现整屏异常抖动或遮挡。
  - 证据：动效截图或视频片段。
- [ ] 检查倍数展示。
  - 操作：记录炸弹 / 火箭前后的倍数。
  - 预期：倍数按规则累乘；UI 显示与结算一致。
  - 证据：前后倍数记录。

### 5. 结算、重开与返回

- [ ] 打完本局。
  - 操作：继续出牌直到任一玩家手牌为 0。
  - 预期：立即进入结算；胜负、地主 / 农民、倍数、得分展示明确。
  - 证据：结算截图。
- [ ] 检查结算弹窗。
  - 操作：观察结算弹窗在当前分辨率下的位置和按钮。
  - 预期：弹窗不溢出屏幕；重开 / 返回入口可点击。
  - 证据：结算全屏截图。
- [ ] 重开一局。
  - 操作：点击重开或新一局。
  - 预期：进入新一局初始状态；上一局结算不残留到新局牌桌。
  - 证据：新局首屏截图。
- [ ] 返回大厅。
  - 操作：从结算或可用入口返回大厅。
  - 预期：大厅战绩更新；设置和难度状态仍正确。
  - 证据：返回大厅截图。

## 断局恢复

- [ ] 制造断局。
  - 操作：开局后至少完成叫抢，并进行一次玩家出牌；随后关闭预览或刷新页面。
  - 预期：关闭 / 刷新不产生错误弹窗。
  - 证据：关闭前牌桌截图。
- [ ] 恢复断局。
  - 操作：重新打开项目或刷新后回到大厅，点击继续 / 新局入口中的恢复路径。
  - 预期：能恢复到合法局面；当前玩家、手牌数量、倍数、上一手信息与关闭前一致或符合已记录的恢复规则。
  - 证据：恢复后牌桌截图。
- [ ] 恢复后继续游玩。
  - 操作：继续至少两轮玩家 / AI 行动。
  - 预期：出牌合法；AI 不无限等待；可继续进入结算。
  - 证据：恢复后行动截图。

## 设置与战绩持久化

- [ ] 设置持久化。
  - 操作：在大厅切换音效、震动、动效和难度；关闭并重新打开。
  - 预期：重新打开后设置仍保持最后一次选择。
  - 证据：重启前 / 后设置状态记录。
- [ ] 战绩持久化。
  - 操作：完成一局后记录局数、胜率、净分；关闭并重新打开。
  - 预期：战绩没有回退或重复累计；重启后展示与关闭前一致。
  - 证据：重启前 / 后战绩截图。
- [ ] 断局与战绩边界。
  - 操作：进行一局未结算的断局恢复，不完成结算直接返回大厅。
  - 预期：未结算局不应计入已完成战绩；若当前设计不同，需要记录设计说明。
  - 证据：战绩变化记录。

## 异常路径抽查

- [ ] 无人叫地主重发。
  - 操作：尽量选择不叫；若 AI 全部不叫，观察重发流程。无法自然覆盖时记录“未触发，待固定种子补测”。
  - 预期：无人叫地主后重新发牌；不会停在无行动状态。
  - 证据：重发前后截图或缺口记录。
- [ ] 连续过牌后牌权回归。
  - 操作：让一名玩家出牌后，后续玩家连续不要。
  - 预期：牌权回到上一手出牌玩家；可自由出牌。
  - 证据：上一手与当前行动提示截图。
- [ ] AI 不阻塞。
  - 操作：连续等待 AI 行动不少于 10 次。
  - 预期：AI 每次在合理时间内完成；没有无限 thinking 或按钮锁死。
  - 证据：过程记录。
- [ ] 非法操作防护。
  - 操作：不选牌时点击出牌，或选择不合法组合后点击出牌。
  - 预期：不能提交非法动作；提示或按钮禁用状态清楚。
  - 证据：非法操作前后截图。
