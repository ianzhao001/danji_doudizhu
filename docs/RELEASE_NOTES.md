# 发布说明

## v1.9（2026-07-18）——玩家打回整改：翼牌决策根治 + 提示体验重构（W-AI-R2）

### 玩家两条打回，逐条整改

- **困难档飞机不再甩出大牌 2**：玩家实测「飞机带出较大牌型 2，手上却有小的单牌 3」。根因是旧评分**字典序独裁**（结构分 ×10000 压死留牌信号，留 2 只值 +36）；重构为**毫手量纲评分**——弃控牌罚把「甩掉绝对顶张 2」标价为超过一整手结构的代价，仅真能一手清完收官时豁免。同手牌实测对照：旧引擎打 `888999+10+2`、新引擎领顺子 `34567` 留 2。机检门 `wing-regression` 钉死此决策（对旧引擎红、对新引擎绿）。
- **提示体验重构**：三病灶根治——① 连按不再跌回「小到大轮圈」，改为按质量排序的榜单内轮换（N≤6，同型飞机翼变体去冗、连按不刷屏）；② AI 建议过牌时不再静默哑火，弹提示「建议不出，保留手牌」；③ 手动改选手牌后提示不再被劫持，视同重新首按覆盖为最优着法。首按覆盖率提升到 PIMC 高预算档 + 叶端明牌精确解委托（与困难 AI 同一大脑）。

### 强度与工程

- **三档 AI 再上台阶**（镜像换位 200 seed×双向=1200 局/档）：困难 **+20.17pp**（v1.8 为 +10.17pp）、普通 **+10.5pp**、简单 **+32.17pp**；self 精确 0、crippled −55pp 被反向门抓住；quality 三档单调分层、压队友率 0。
- **新增明牌世界精确解**（`ai/worldSolver.ts`）：残局采样世界内跑三家两阵营极大极小（农民同盟效用、置换表跨采样共享、节点预算护栏），超阈值或预算耗尽自动回退 rollout——困难强度由此再 +3.33pp。
- **过牌推断加权采样**：从出牌历史识别「非配合性过牌」对采样世界降权，以 ESS 有效样本量护栏防极端历史带偏，一键可关断。
- 全量基线：**195 个测试文件、1227 个用例通过、2 个跳过**，typecheck 通过；冷构建 exit 36/builtins 33；决策与提示耗时全部在门内（ranked 提示 ×100 max 240.9ms < 400ms 门）。
- **工艺诚实披露**：本波种子按「红先行」纪律逐枚负向自证，六次发现自证夹具哑火均以**修订夹具或改派单点权威门**处理，无一调低门槛或删断言消红；一处 `PimcProfile` 配置扩展遇 v1.8 老门的完整键集深锁，用不可枚举属性承载（低危，已登记偿还路径，见 KNOWN_LIMITATIONS）。

## v1.8（2026-07-17）——AI 全难度大幅强化 + 结算口径修复（W-AI）

### 玩家可感变化

- **三档 AI 全体大幅变强**（新旧引擎同牌换位对战实测）：困难 **+10.17pp**、普通 **+8.33pp**、简单 **+32.17pp** 胜率差；三档差距保持单调（困难>普通>简单），不会互相吃掉。
- **简单档告别"一次一张"**：会打组合、懂基础配合，不再拆炸弹送分（难度描述文案同步更新）。
- **困难档新增"猜牌"与"残局精算"**：确定化蒙特卡洛（PIMC）对未见牌采样模拟 + 残局必胜精确解 + 记牌控权。
- **提示显著变聪明**：与困难档同引擎、更高采样预算（单次 <50ms）；首按最优推荐、连按轮换候选。
- **叫牌建议与 AI 同口径**：烂牌不再怂恿抢地主（旧"一张高牌就叫"的口径分裂已修复）。
- **结算面板滚分改为连打累计**：每席显示 本局±分 + 累计±分 + 余牌，滚动作用于累计列；「再来一局」累计延续，回大厅清零。
- **终局最后一手不再被吞掉牌型气泡**：结算面板延后约 0.6 秒放行（关闭动效则直显）。

### 工程与验证

- 新增 6 个 AI 纯层模块与 2 个 UI 纯岛，全部零 `cc` 依赖、零时基、零随机源泄漏；**AI 决策确定可复现**（同局面恒同决策，PIMC 种子由公开局面派生）。
- 新增镜像换位竞技场（含 self/crippled 双自证与 weights-only 消融档）、着法枚举完备性门、合法性零违规门、PIMC 确定性门、决策耗时门（p95 8.3ms / 提示 max 46ms，门槛 60/400ms）。
- 全量基线：**188 个测试文件、1162 个用例通过、2 个环境门控跳过**，typecheck 通过。

### 开源借鉴（详见 [docs/AI_DESIGN.md](AI_DESIGN.md)）

本版 AI 借鉴了以下开源项目的**算法思想与评估方法论**（未复制代码、运行时零依赖）：

- [datamllab/rlcard](https://github.com/datamllab/rlcard)（MIT）——斗地主规则 Agent 作朴素基线参照。

PIMC 确定化蒙特卡洛与残局 negamax+置换表为自研实现（通用算法思想）。感谢以上开源作者。
