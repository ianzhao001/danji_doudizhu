## 背景（关联规划书 §3 约束二、§6 T-0）

两巨组件各有一套近似重复的 UI helper，且存在**行为差异**。抽取为共享自由函数，避免 P-G/P-L 并行改 `addButton`（加按压态）时分叉。**这是同形重构 + 一处 bug fix，不改布局/视觉。**

## helper 差异裁决表（严格按此，勿过度抽取）

| helper | 差异 | 统一方向 |
|---|---|---|
| `addUiTransform` / `loadSprite` | 逐字相同 | 直接抽为自由函数 |
| `drawHudPanel`/`drawPanel` | 仅函数名不同，逻辑同 | 抽为一函数，任选一名 |
| `drawButtonBackground` | game 3 参 / lobby 4 参（带 `selected` 影响 fillColor） | 统一 4 参，game 调用传 `selected=false` |
| `addLabel` | 默认值/lineHeight/color 参数不同 | 全参数化 + 默认取并集；**fontSize 由调用方显式传**（避免视觉变） |
| `addButton` | game=get-or-add + `off`→`on`；lobby=裸 `addComponent(Button)` | 统一到 **get-or-add + off/on**（**bug fix**）；签名合并 `name?`+`selected?`；fontSize 调用方传 |
| `labelColor` | game 自由函数被 `addButton` 调；lobby 内联 | 随 `addButton` **内联进 extracted 版或改参数**，**不从 `ui-helpers.ts` 导出** |
| `ensureNode` | game 带私有 `liveRenderNodes` diff 跟踪；lobby 无 | **不抽**，留各自组件 |
| `drawDimOverlay`/`strengthColor` | game 专属 | **不动** |

## 行为要求
1. 抽取上表标「直接抽/统一」的 helper 为自由函数（显式传 `parent`/`owner`/配置项，**非基类**）。
2. `addButton` 统一到 get-or-add + off/on（消除 lobby 的裸 addComponent 潜在重复监听）。
3. 两组件删除本地重复实现、改为 import `ui-helpers.ts`；`ensureNode` 与 game 专属 helper 保留原处。
4. **不改任何布局坐标、fontSize 默认、视觉**（fontSize 由调用方显式传保持原值）。
