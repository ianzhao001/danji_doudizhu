## 背景（关联规划书 §1、§6 E-0；架构核实）

横屏化的功能驱动点。已核实：两场景的 Canvas 均挂 `cc.Canvas` 组件，运行时**自动把节点 `UITransform.contentSize` 适配到设计分辨率**——即 `.scene` 里烘焙的 390×844 只是设计期视图，运行时 `canvasSize()` 读到的是按 `project.json` 设计分辨率适配后的横屏尺寸。故**改 `project.json` 设计分辨率即可让运行时/Creator 预览翻横屏**，无需手写 `.scene`（本仓库禁手写 `.scene`/`.meta`）。

当前值（[project.json](../../settings/v2/packages/project.json)）：
```json
"designResolution": { "width": 390, "height": 844, "fitWidth": true, "fitHeight": false }
```

## 行为要求
把 `general.designResolution` 改为横屏 FIXED_HEIGHT：
```json
"designResolution": { "width": 844, "height": 390, "fitWidth": false, "fitHeight": true }
```
- `width>=height`（844≥390）→ 触发 T-A1 的 landscape 分支。
- `fitWidth:false, fitHeight:true`（FIXED_HEIGHT）→ 高度锁 390、宽度随屏延展，适合横屏。
- **只改这四个字段值**，不动 `__version__`、不加别的键、不碰其它文件。

## 不在本任务内（交代清楚，避免夹带）
- **方向锁（orientation=landscape）**：属**构建面板**配置（存 gitignored `profiles/` 构建 profile，非 tracked 文件）。由构建者（用户）在 Build 面板设 Orientation=Landscape，随构建产出 `build/web-mobile/src/settings.json` 的 `screen.orientation`。**不在执行者文件域**，作为构建时清单项。
- **`.scene` Canvas contentSize**：运行时 `cc.Canvas` 自适配，无需改；禁手写 `.scene`。
- **背景占位**：归 P-G/P-L 运行时画。
