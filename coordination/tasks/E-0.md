## 背景（关联规划书 §1、§6 E-0、§7 Wave 1）

竖屏→横屏的编辑器侧翻转。当前 `project.json` 为 `390×844 / fitWidth:true / fitHeight:false`，构建 `settings.json` 为 `orientation:"auto"` + `designResolution 390×844 policy:4`。本任务把工程翻到横屏，供 P-G/P-L 在真实横屏画布上预览验收。

## 行为要求（在 Creator 中操作）
1. **Design Resolution**：`390×844` → **`844×390`**；**`fitWidth:true→false`、`fitHeight:false→true`**（横屏用等高适配）。
2. **方向**：项目/构建 orientation → **landscape**。
3. **两场景 Canvas**：`game.scene`、`lobby.scene` 的 Canvas UITransform contentSize → `844×390`，位置 `(422,195)`；保留 Widget 全拉伸 + SafeArea（横屏刘海内缩在**左右**）。
4. **不动背景视觉**：不改 `background` 精灵加载逻辑、不加背景节点（占位背景由 P-G/P-L 运行时画）。若 Canvas 尺寸变更导致 scaffold 节点位置偏移，仅由 Creator 生成，不手写 `.scene`。
